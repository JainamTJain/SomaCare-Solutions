# Cost to acquire one paying home

This page is a formula. It is not a measurement. Sorety does not have a count of Los Angeles administrators in this repository, and it does not have a conversion rate. Every number below that is not the formula is a guess. Do not put the illustration in a deck.

The review's point stands: customer acquisition likely dominates the hardware bill. A six-bed home at a private-pay price is a small contract and a long consent process. Until outreach hours, install time, consent time, and conversion are filled in from real attempts, there is no cost-to-acquire figure.

## Formula

```
cost_per_attempt = (outreach_hours + install_hours + consent_hours) * loaded_hourly
                   + travel_and_hardware_consumed
paying_home_cost = cost_per_attempt / conversion_rate
```

`conversion_rate` is homes that start paying, divided by homes contacted. A facility that denies the camera counts as a contact and not as a win.
